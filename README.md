# AGRICA

### AI-powered agriculture for Africa — starting with Ethiopia

AGRICA is an AI-driven agricultural platform connecting farmers and buyers while providing agronomy support through web, mobile, and future offline voice systems.

This version is a **demo for AGRICA Ethiopia**, built with **Amharic support**, and designed as the foundation for expansion across Africa.

Future vision:

* AGRICA Ethiopia
* AGRICA Kenya
* AGRICA Tanzania
* AGRICA Nigeria

Each localized for language, crops, and market systems.

# Inspiration

Millions of African farmers lack access to:

* Professional agronomists
* Fair marketplaces
* Reliable crop diagnosis
* Modern agricultural tools

Most agri-tech platforms assume internet and smartphones.

AGRICA is built to change that.

# Current Features

## AI Agronomist

Farmers can interact with an AI agronomist through:

* Text
* Voice

It helps with:

* Crop disease detection
* Soil issues
* Farming advice
* Best practices

Current demo supports:

* Ethiopian farmers
* Amharic language

Powered by Google Gemini API.

---

## Marketplace

Farmers can:

* Create crop listings
* Add crop images
* Set price and quantity
* Manage listings

Buyers can:

* Browse crops
* View listings
* Contact farmers directly

This reduces middlemen and creates fairer trade.

---

## Verified Crop Badge

Farmers can optionally upload up to **3 crop images** when listing.

AGRICA uses AI to review:

* Crop authenticity
* Crop quality
* Listing accuracy

If approved, the listing gets a **Verified Badge**.

Benefits:

* Builds buyer trust
* Highlights quality produce
* Reduces fake listings

# Installation

## Clone repository

```bash
git clone https://github.com/adel-kd/agri-project.git
cd AGRICA
```

## Backend

```bash
cd backend
npm install
npm start
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
